# pi-agent v0.19.87 更新

本版本为开发版增加可选的 Ego Lite 外部浏览器执行后端，并保留内置浏览器作为默认选项。

## 新功能

- **Ego Lite 外部浏览器** — 可在通用设置中准备并选择外部浏览器，用于符合条件的前台 Agent 运行；支持导航、观察、点击、填写、等待、截图和交接给用户。
- **浏览器配置选择** — 默认复用当前 Ego Profile，也可显式选择工作区独立 Profile；工作区与会话仍分别绑定 TaskSpace。

## 体验优化

- **本轮后端状态** — Agent 运行时显示本轮选用的网页后端；回退到内置浏览器时说明原因，便于区分实际控制的浏览器。
- **复检保留偏好** — Ego Lite 复检期间新运行暂用内置浏览器，复检完成后继续按已保存的选择路由；取消复检不会意外更改后端偏好。

## 安全与兼容

- **内置浏览器保持默认** — 右侧浏览器、手动链接和本地预览继续使用内置浏览器；外部浏览器仅在受支持的开发版前台运行中启用。
- **失败操作不自动重放** — 外部操作结果不确定时停止派发并提示检查页面，避免重复执行可能已送达的操作。
