# pi-agent v0.19.78 更新

本版本优化会话侧栏，并修复 IntelliJ IDEA MCP 长连接和 Fork 工作区复制中的问题。

## 体验优化

- **Agent 会话侧栏** — 活跃会话列表按可见范围渲染，切换会话时自动定位，并避免较旧的刷新结果覆盖新的列表状态。
- **开发环境启动** — 补充 Windows 和 Unix 启动脚本及开发说明。

## Bug 修复

- **Chat 删除反馈** — 区分删除失败与删除后列表刷新失败。
- **删除确认弹窗** — 避免原生浏览器视图遮挡弹窗，并支持在较小窗口内滚动。
- **IntelliJ IDEA MCP** — 避免空闲 SSE 连接被默认的响应体超时切断。
- **Fork 工作区** — 文件复制遇到暂时性 ENOENT 时进行有限重试。
