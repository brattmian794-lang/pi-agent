# pi-agent v0.19.91 更新

本版本集中收敛诊断日志的噪音与超时语义，修复已记录的 25 个问题，并完善 Ego Lite 外部浏览器的可观测性。

## 新功能

- **Ego Lite 运行诊断** — 客户端启动、任务空间创建或复用、派发停止与拒绝都会输出结构化事件，只包含固定原因码、耗时和哈希标识，不写入页面内容与异常原文。
- **任务空间自动恢复** — Ego 任务空间被外部删除时不再整体失败，而是明确返回「任务空间已缺失」，下次操作按需重建。
- **默认 GitHub 发布 Skill** — 随应用内置 `github-stable-release` Skill，把版本准备、提交、打 tag、构建与发布校验串成一条可复核的流程。

## 产品调整

- **应用身份统一为 pi-agent** — 受管浏览器 UA、内置浏览器 Skill 与工程约定由 Proma 统一改为 pi-agent；页面仍保留 Chromium 兼容 token，站点可正常识别能力。

## 体验优化

- **诊断日志分级与去重** — 更新器、WebSocket、CDP、ResizeObserver、KaTeX 与消息截断的重复或兼容性告警改为一次性提示，并保留可定位的阶段与视图上下文。
- **Bun 与更新状态可见** — 设置页新增 Bun 运行时卡片并展示不可用原因；检查更新失败时会标注是否可重试。

## Bug 修复

- **受管浏览器超时** — 导航、快照、脚本与操作高亮超时返回结构化状态（含 unknown 与可重试标记），超时不再被当成成功，侧栏也不会重复创建标签。
- **应用更新** — Windows 不再请求缺失的差分更新文件；NSIS 安装行为显式配置；同一次检查失败只记录一条日志并标记可重试。
- **Agent 运行时** — 区分「运行时已停止」与「取消失败」，结果未知时不再误报已取消；延迟消息投递失败会重新入队并记录后续投递结果。
- **会话标题** — 区分账户额度不足、请求超时、网络故障与响应解析失败，回退本地标题时给出具体原因。
- **工具校验与大消息** — Write 超限时返回分段写入方案，参数缺失日志指出具体字段，超大消息截断后不再超限。
- **安装包与图标** — Windows 产物包含 icon.ico 与 icon.icns，图标缺失时回退系统默认图标并列出已查找路径。
