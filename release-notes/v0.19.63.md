# Proma v0.19.63 更新

## 稳定性修复

- 修复 Pi Agent 流读取错误及常见瞬时连接中断未自动重试的问题。
- 扩展上游响应流结束、JSON 解析和分块读取异常的瞬时错误识别。

## 依赖升级

- Pi Agent SDK 从 `0.87.1` 升级到 `1.4.0`。

## macOS 构建

- 当前 Fork 未配置 Apple Developer ID 签名证书时，macOS 构建会跳过签名准备并产出未签名安装包。

- **macOS Intel** — `Proma-0.19.63.dmg`
- **Windows** — `Proma-Setup-0.19.63.exe`
- **Linux AppImage** — `Proma-0.19.63.AppImage`
- **Linux deb** — `proma_0.19.63_amd64.deb`
