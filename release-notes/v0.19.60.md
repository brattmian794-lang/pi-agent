# Proma v0.19.60 更新

## 稳定性修复

- 修复 Pi Agent 流读取错误及常见瞬时连接中断未自动重试的问题。
- 扩展上游响应流结束、JSON 解析和分块读取异常的瞬时错误识别。

## 依赖升级

- Pi Agent SDK 从 `0.87.1` 升级到 `1.4.0`。
